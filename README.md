# test

`access.json` controla si la app de escritorio **iDempiere Productos** se puede usar:

- `"access": true`  → la app funciona.
- `"access": false` → la app muestra "Acceso deshabilitado" y se cierra.

La app lo comprueba al abrirse y cada 30 minutos; el cambio puede tardar unos minutos en
aplicarse (caché de GitHub). Este repositorio debe seguir siendo **público**.
